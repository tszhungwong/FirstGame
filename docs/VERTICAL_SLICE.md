# Game Ghost 垂直切片

> 目標：以灰盒或臨時素材完成一段 15–20 分鐘的可玩內容，驗證移動、戰鬥、探索、劇情與能力解鎖能否形成完整循環。
>
> 本文件只定義玩法範圍與驗收結果。程式模組與資料流以 [`ARCHITECTURE.md`](./ARCHITECTURE.md) 為準；動畫、字型與匯入規格以 [`VERTICAL_SLICE_ART_ASSETS.md`](./VERTICAL_SLICE_ART_ASSETS.md) 為準。

## 平台與技術

- Godot 4.8
- GDScript
- Windows PC
- 僅支援鍵盤

## 可玩流程

1. 主角在廢棄維修區醒來。
2. 玩家學會移動、跳躍、下穿平台與普通攻擊。
3. 玩家遇到第一種敵人並學會收集記憶能量。
4. 玩家取得技能並學會方向組合招式。
5. 玩家遇到可交談 NPC「守燈人」。
6. 玩家讀取一段與主角過去有關的記憶片段。
7. 玩家通過一段平台與戰鬥混合路線。
8. 玩家擊敗小型 Boss。
9. 玩家取得永久探索能力「磁力攀附模組」。
10. 玩家返回先前路線，使用新能力開啟出口。

## 玩家能力

- `A/D`：左右移動
- `Space`：跳躍
- `S`：穿越單向平台
- `L`：衝刺
- `J`：普通攻擊
- `K`：技能
- `E`：與附近物件互動；對話框顯示時用來關閉並繼續
- 靠近可互動角色或物件時，只在最近的目標上方顯示「按 E 互動」
- `W/S + J`：向上／向下普通攻擊
- `W/S + K`：向上／向下技能
- 左右方向只鏡像同一招式
- 擊敗小型 Boss 後取得磁力攀附模組，可在牆面緩降並蹬牆跳躍

## 操作手感

- 移動快速起步，不使用明顯的加速延遲
- 按住跳躍鍵可跳上目前的平台高度，提早放開則形成明顯較低的短跳
- 玩家可在空中微調橫向位置
- 衝刺距離短且反應快
- 普通攻擊只短暫限制移動
- 命中時使用極短停頓、擊退與清楚的視聽反饋表現重量
- 寫實美術不等於真實慣性；精確操作優先於物理擬真

## 戰鬥系統

- 固定主武器：回響切割器
- 普通攻擊命中敵人時獲得記憶能量
- 技能消耗記憶能量，不使用一般冷卻時間
- 主角具有生命、受傷擊退、短暫無敵與死亡重生
- 垂直切片包含兩種普通敵人和小型 Boss「殘響監工」

## 死亡與重生

- 死亡後回到最近啟用的維修節點
- 維修節點首次啟用提示顯示 2 秒，之後再次經過不重複顯示
- 重生時生命完全恢復，記憶能量恢復至容量的一半
- 普通敵人重生
- 已啟動的機關、已讀取的記憶與已取得的永久能力不重置
- 垂直切片不掉落貨幣，也不生成需要返回死亡地點回收的分身
- 死亡代價以重新通過一小段路線為主，不以永久損失懲罰玩家

### 殘響監工

- 使用重型維修外骨骼
- 以重型切割臂、衝撞和落下的機械零件攻擊
- 戰鬥中說出殘缺的工作口令
- 三句戰鬥台詞依序各播放一次，播完後不在同一場戰鬥重複
- 被擊敗後短暫認出主角，並留下磁力攀附模組
- 戰後記憶片段揭露他曾協助主角反抗監理者

### 失憶工人

- 在固定地面路線徘徊
- 接近玩家後使用緩慢且有明顯預備動作的工具揮擊
- 用於教導閃避、攻擊距離與受傷擊退

### 巡檢浮機

- 在空中與玩家保持距離
- 發射慢速電弧，玩家接近時會嘗試升高或後退
- 用於教導向上攻擊、跳躍攻擊與方向技能

## 劇情內容

- 可交談 NPC「守燈人」
- 一段可讀取的記憶片段
- 監理者首次透過廣播與主角接觸
- 經過區域自動出現的對話，每個觸發區在同一輪遊戲中只顯示一次
- 小型 Boss 與廢棄維修區的歷史相關
- 不在切片中解答中央核心與主角過去的完整真相

### 守燈人

- 位於仍有輔助供電的小型值班室
- 認得主角的制服與回響切割器，但對主角保持戒心
- 告知玩家殘響監工正在封鎖出口
- 引導玩家讀取第一段記憶，不直接講解全部背景
- Boss 被擊敗後離開值班室，表示該居民已獲救

## 美術範圍

- 使用幾何圖形、簡單色塊或明確標示的臨時素材
- 主角、敵人、地圖與攻擊效果皆可使用不同顏色的幾何圖形表示
- 優先確保角色、敵人、地形、攻擊範圍和互動物容易辨識
- 不製作正式角色動畫、完整光影、最終特效或完整介面
- 不加入音樂或角色語音
- 對話以純文字呈現；原型可暫時完全靜音

## 完成標準

- 玩家能從開始位置完成整段流程，無阻斷性錯誤
- 移動、跳躍、衝刺和下穿平台可以穩定操作
- 角色移動反應靈活，攻擊命中具有可感知但不妨礙操作的重量
- 普攻、方向攻擊、記憶能量與方向技能構成可理解的戰鬥循環
- 玩家能死亡並從存檔點重新開始
- 重生後保留機關、記憶與永久能力進度，生命全滿且記憶能量為容量的一半
- 擊敗 Boss 後獲得磁力攀附模組，並能以蹬牆跳開啟先前無法通過的垂直路線
- 完整遊玩時間約 15–20 分鐘

## 明確排除

- 完整地下城邦
- 正式美術與完整動畫
- 音樂與角色語音
- 多武器系統
- 多結局
- 手把、滑鼠操作與其他平台
- 背包、裝備和大型技能樹
- 最終 Boss 與故事結局
